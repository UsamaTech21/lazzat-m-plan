# lazzat-m-plan

Lazzat 360° Digital Marketing Master Plan — static site ready for Vercel deployment.

## Pages

- `index.html` — Marketing master plan & to-do tracker
- `competitor-analysis.html` — Competitive intelligence matrix
- `eid-deals.html` — Eid deals campaign analysis
- `launch-plan.html` — 30-day launch blueprint
- `menu-content-calendar.html` — 25-post content calendar
- `social-media-strategy.html` — Social media playbook
- `usp-section.html` — Brand USP & ICPs

## Deploy on Vercel

Import this repo on [vercel.com/new](https://vercel.com/new) — no build command required.
